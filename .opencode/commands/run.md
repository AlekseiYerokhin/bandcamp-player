Run the app from source using the project's virtualenv:

```bash
venv/bin/python main.py
```

The app is a GUI and will block while running. If you need to keep the
terminal, launch it in the background. Otherwise let it run a few seconds,
confirm it starts without errors, and report what you observe (startup
messages, any tracebacks).
